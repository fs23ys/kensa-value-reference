# 検査値リファレンスアプリ 引き継ぎメモ

## プロジェクト概要
薬局薬剤師が検査値・疾患の説明を即座に引くための個人用ツール。要件の正本は `検査値アプリ_指示書.md`。

## 成果物(納品物・このまま使える)
- `..\検査値リファレンスアプリ.html` … 単一HTMLファイルのアプリ本体(SheetJS内包・オフライン動作)
- `..\検査値リファレンス初期データ.xlsx` … 初期データ(検査値58件・疾患15件、2026-07-26時点)

## ソース一式(このフォルダ `_source\`)
アプリ本体・Excelはこのソースから生成している。今後の追加・修正は、直接HTMLをいじるのではなく、ここを編集して再生成すること。

| ファイル | 役割 |
|---|---|
| `initialData.js` | 検査値・疾患の初期データ本体(配列)。新しい検査値・疾患を追加する時はここを編集 |
| `buildExcel.js` | initialData.js → `検査値リファレンス初期データ.xlsx` を生成 |
| `app.js` | アプリのロジック本体(検索・カード表示・並び替え・アプリ内編集など) |
| `app.css` | アプリのスタイル |
| `assemble.js` | app.css + xlsx.core.min.js(SheetJS) + app.js を1つのHTMLに結合 |
| `node_modules/xlsx` | SheetJS(Excel読み書きライブラリ)。npm install 済み |

### 再生成コマンド(PowerShell、このフォルダで実行)
```powershell
node buildExcel.js "..\検査値リファレンス初期データ.xlsx"
node assemble.js "..\検査値リファレンスアプリ.html"
```

## 今のアプリでできること
- Excel読み込み(検査値・疾患2シート)、次回起動時は自動復元
- 全列対象の検索(全角半角・カタカナひらがな・長音記号の表記ゆれを吸収)
- 検査値カード⇔疾患カードの相互リンク、関連検査値の自動抽出
- 疾患ごとの「確認すべき検査値」は疾患タグから自動生成(手入力不可)
- 高値/低値の生活・食事アドバイス表示、参考ページ欄
- 未収載メモ(0件検索→記録→コピー/CSV書き出し)
- 一覧のタブ切り替え(検査値=緑／疾患=黄)、ドラッグ&ドロップ/▲▼ボタンでの並び替え(ブラウザに保存)
- **アプリ内での文言編集**(カード右上「✎ 編集」)。保存はブラウザ内のみ、Excelファイルは書き換えない。他端末には反映されない
- **Excelとして書き出す**ボタン(2026-07-26追加)。読み込み後にツールバーに表示され、アプリ内編集を含む現在のデータを新しい.xlsxとしてダウンロードできる。マルチデバイス利用時はこれを他端末に持って行ってインポートすることで手動同期する運用

## 絶対に守ること(指示書より)
- 疾患名・検査値名をコードに書かない(すべてExcel/initialData.js由来)
- 数値の自動判定機能は作らない
- 暗記・学習機能は作らない
- クラウドDB(Firebase等)は使わない、オフライン完結

## 運用の考え方(この会話で確認済み)
- 依頼者は医学知識の調査・Excelへの記入をすべてClaude(私)に依頼する運用。依頼者が自分でExcelを編集することは想定していない
- 新しい検査値・疾患の追加/削除/内容修正は、依頼者が名前や内容を伝えるだけで、Claude側が `initialData.js` を編集→再生成する
- ちょっとした言い回し修正は、依頼者がアプリ上の「✎ 編集」で直接できる(この場合Excelには反映されないので、大きな追加をする時は事前にアプリ側の編集内容を聞いて反映すること)
- GitHubやcrowd同期の話も出たが、今のところ未着手。マルチデバイス利用の要望が出たら検討

## 未着手・保留中の話題
- 肺機能検査(FEV1・ピークフロー等)は「生理検査」として除外済み(血液・尿検査のみ収載する方針)
- Excel書き出しボタンは2026-07-26に実装済み(マルチデバイス利用の要望があったため、当初の「作らない」方針から変更)
- `ビタミンD(25(OH)D)` 疾患タグに残っている「栄養」は対応する疾患カードが未作成(自動生成の空カードとして表示される。旧データ由来、今回のセッションでは未対応)

## 2026-07-26のセッションで追加した内容
- カリウムの基準値を修正(3.5〜4.5→3.5〜5.0 mEq/L、5.5以上で高カリウム血症)
- クレアチニン・eGFR項目にCKD重症度分類(G1〜G5)、標準化/個別化eGFRの違いを追記
- 新規検査値6件: クレアチニンクリアランス(CCr)、TSH、FT4、血小板(Plt)、PT-INR、血中薬物濃度(TDM)
- 白血球(WBC)のスタブ項目を全項目埋めて充実化
- 甲状腺の自己抗体2項目(抗TPO抗体・抗サイログロブリン抗体)の疾患タグを「甲状腺機能低下症」→「甲状腺疾患」に統一
- 新規疾患6件: てんかん、抗凝固療法（心房細動・血栓症）、抗血小板療法、甲状腺疾患、精神疾患（非定型抗精神病薬）、がん治療薬（`在庫医薬品_疾患分類_血液検査モニタリング.xlsx`の「血液検査モニタリング一覧」シートを参考に選定）
- 既存検査値(AST/ALT/LDL/HbA1c/血糖/クレアチニン・eGFR/BUN/CCr/ヘモグロビン)の疾患タグに上記新疾患を追記し、確認すべき検査値が自動生成されるようにした
- アプリに「Excelとして書き出す」ボタンを追加(app.js / assemble.js)。マルチデバイス利用時の手動同期用途
- `..\検査値アプリ_モックアップ.html`(依頼者作成の画面イメージ)の配色・タイポグラフィにapp.cssを全面的に寄せた。深緑(#14524A)基調、患者説明例は濃色の目立つボックス、薬剤師補足はゴールド系のノート風、高値/低値はそれぞれ赤系/青系の背景。一覧のタブ切り替え構造(検査値/疾患)自体はモックアップのタグサイドバー方式に変えず、そのまま維持
